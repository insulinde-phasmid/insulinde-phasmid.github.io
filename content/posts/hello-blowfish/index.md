博客已经搭建完成。这篇文章采用 Hugo 推荐的页面包结构，因此可以直接在同一目录中添加封面和正文图片。

## 开始写作

复制本文章目录，修改 `index.md` 的标题、日期和正文，就可以发布新文章。

```bash
./bin/hugo server -D
```

本地预览确认无误后，运行 `./bin/hugo --minify` 生成可部署的网站文件。
